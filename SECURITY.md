# Website security

Report Certael security issues through the private advisory flow in the affected repository:

- [Certael Core advisory](https://github.com/violetweather/Certael/security/advisories/new)
- [Certael Agent security policy](https://github.com/violetweather/Certael-Agent/blob/main/SECURITY.md)

Do not disclose exploitable issues through a public website issue. The website contains no authentication, backend, player telemetry, or production signing material.
